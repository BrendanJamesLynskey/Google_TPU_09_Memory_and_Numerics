# Memory Hierarchy &amp; Numerics

The six-tier TPU memory hierarchy &mdash; PE registers, accumulator SRAM, VMEM, CMEM, HBM, remote HBM via ICI &mdash; and the numeric story that goes with it (INT8, bf16, FP8, FP32 accumulators). Why bfloat16 is Google Brain's most influential invention. Why every TPU generation uses the "halve precision, double FLOPS" lever. Why TPUs don't yet have FP4.
